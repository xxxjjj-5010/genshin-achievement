# 原神成就统计 · 升级包

> 生成时间：2026-09-18 ｜ 数据版本：游戏 7.0「无神怜爱的雪国」（上游 2026-08-11）

## 这个包解决三个问题

1. **数据落后一个版本**：原 `data.js` 停在 6.8（1759 个成就），7.0 的 86 个新成就不在里面。
2. **更新即错位的隐患**：原 key 是「文件::合辑::序号」，序号会随版本插入新成就整体后移。
   实测直接用新数据覆盖，1759 条已保存进度里 **370 条会静默指向错误的成就**、518 条变无主数据。
3. **进度无处备份**：原来只能导出纯文本（无法回导），删账号也没有二次确认。

## 包含文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 与线上一致，**未改动** |
| `app.js` | 升级版逻辑：键位迁移 + 修复 + 新功能 |
| `style.css` | 修复 3 处样式问题 + 新增组件样式 |
| `data.js` | 7.0 数据（1845 项 / 73 合辑 / 14030 原石），key 用稳定 id |
| `tools/build-data.mjs` | 数据生成脚本，从上游拉取最新成就 |
| `.github/workflows/sync-achievements.yml` | 每天自动同步，有变化才提交 |

## 怎么用

1. 用本包的 `index.html`、`app.js`、`style.css`、`data.js` 覆盖仓库根目录的四个文件。
2. 把 `tools/` 和 `.github/` 两个文件夹一起提交进仓库。
3. 等 GitHub Pages 重新部署（约 1 分钟），打开网站确认进度还在。

`index.html` 只有一处可选改动：`<title>` 或页脚可以加上数据版本，方便一眼确认是否最新。

## 为什么已保存的进度不会丢

- 成就 key 从「文件::合辑::序号」换成游戏内**稳定成就 id**（如 `81032`），上游怎么增删都不影响已有勾选。
- `data.js` 里带了 `LEGACY_KEY_MAP`（1759 条旧键 → 新 id 的完整映射）。
- 首次进入某个 UID 时自动转换并回写 localStorage，之后就是原生新格式；重复进入不会重复转换。
- 旧文件里 4 条无法用「名称+描述」自动匹配的（上游给 `QUEST FAILED` 改了名、3 条同名「最终枫达海」），已逐条和上下游位置核对后手工指定。

## 新增功能

- **只看未完成 / 只看已完成**：查漏补缺最需要的一环，顶部筛选条；筛选后没有内容的合辑会整块隐藏。
- **隐藏「隐藏成就」**：1845 里有 994 个隐藏成就，可以一键过滤。
- **原石统计**：侧栏显示已获得 / 总原石（14030），还剩多少一眼可见。
- **数据版本显示**：侧栏底部显示游戏版本、上游更新时间、成就总数。
- **暂不可完成标注**：7.0 有 3 个成就当前拿不到（`苍明如冰`、`影域老司机`、`伟业的遂成`三阶段），
  列表里带黄色标签，并从完成度分母里排除——所以显示的是 1842 而不是 1845。
- **JSON 备份与恢复**：导出弹窗里新增「导出备份（JSON）」「导入备份」，换浏览器/清缓存后能原样恢复，导入是合并不覆盖。
- **删除账号二次确认**：删之前弹窗说明不可逆并建议先备份。

## 修复的问题

| 问题 | 处理 |
| --- | --- |
| 反复退出/登录后事件重复绑定 | `initMainEvents` / `initLoginPage` 加绑定标记，只绑一次 |
| 筛选状态下子分类「全选」计数错误 | 子分类记录完整 key 列表（`data-keys`），全选和计数都按全量走 |
| 搜索面板 500px / 弹窗 520px 固定宽度，手机横向溢出 | 加 `max-width: calc(100vw - 24px)` |
| 顶部公告条与导航栏都 `sticky; top: 0`，滚动时互相遮挡 | 公告条改 `position: relative` |
| `style.css` 注释未闭合，吃掉 `.highlight` 规则 | 补上 `*/` |
| `data.js` 加载失败时页面空白无提示 | 加兜底提示条 |
| 搜索结果无上限，某些字一次渲染几百条 | 上限 300 条 |
| UID 校验太松（`1` 也能建号） | 要求至少 9 位数字 |

## 需要你长期维护的两处

1. `data.js` 顶部的 `gameVersionName`：新版本中文名（如 7.1「往冥府的安魂歌」）。
   生成器会保留上一个值，版本更新后手动改一下即可。
2. `app.js` 顶部的 `BLOCKED` 名单：当前版本暂时拿不到的成就，每次版本更新后复核（游戏里点一下就知道能不能拿）。
